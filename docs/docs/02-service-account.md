# 02. Сервисный аккаунт и статические ключи

## 1. Создание сервисного аккаунта

1. Перейдите в **IAM** → **Сервисные аккаунты**.
2. Нажмите **Создать сервисный аккаунт**.
3. Имя: `sa-ml-storage` (или любое удобное).
4. Нажмите **Создать**.

## 2. Назначение ролей

Назначьте сервисному аккаунту роль:

- `storage.editor` — на каталог или на конкретный бакет (предпочтительнее).

Можно использовать более узкие роли:
- `storage.uploader`
- `storage.viewer`

## 3. Создание статического ключа доступа

1. Откройте созданный сервисный аккаунт.
2. Перейдите на вкладку **Ключи доступа** / **Создать новый ключ**.
3. Выберите **Статический ключ доступа**.
4. Нажмите **Создать**.

**Важно!**  
Скопируйте и сохраните в надёжное место:

- **Key ID**
- **Secret Key** (показывается только один раз!)

Эти данные понадобятся для:
- DataSphere S3 Connector
- DVC
- Локального монтирования
