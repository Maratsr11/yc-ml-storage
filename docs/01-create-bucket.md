# 01. Создание бакета Object Storage

## Шаги

1. Откройте [консоль Yandex Cloud](https://console.yandex.cloud).
2. Выберите нужный каталог (folder).
3. Перейдите в сервис **Object Storage**.
4. Нажмите **Создать бакет**.

### Рекомендуемые параметры

| Параметр              | Значение                          | Комментарий |
|-----------------------|-----------------------------------|-----------|
| Имя бакета            | `ml-artifacts-prod` (без точек)   | Имя должно быть уникальным |
| Класс хранения        | Standard                          | Можно потом настроить lifecycle |
| Доступ                | Restricted                        | Только авторизованный доступ |
| Версионирование       | Включить                          | Рекомендуется |
| Шифрование            | По желанию (KMS)                  | Для повышенной безопасности |

5. Нажмите **Создать бакет**.

## Важные замечания

- Не используйте точки в имени бакета (это важно для S3 Connector в DataSphere).
- Лучше сразу создавать отдельные бакеты для `dev`, `staging` и `prod`.
- Запомните точное имя бакета — оно понадобится дальше.
