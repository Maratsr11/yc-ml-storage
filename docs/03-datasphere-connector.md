# 03. Подключение бакета к DataSphere (S3 Connector)

## Создание S3 Connector

1. Откройте нужный проект в DataSphere.
2. Нажмите **Create resource** → **S3 Connector**.
3. Заполните поля:

| Поле                    | Значение                              |
|-------------------------|---------------------------------------|
| Name                    | `ml-s3`                               |
| Endpoint                | `https://storage.yandexcloud.net`     |
| Bucket                  | Имя вашего бакета                     |
| Static access key ID    | Key ID сервисного аккаунта            |
| Static access key       | Создайте Secret и положите туда Secret Key |
| Mode                    | Read and write                        |

4. Нажмите **Create**.

## Активация коннектора

После создания зайдите в карточку коннектора и нажмите **Activate**.

После активации бакет появится в JupyterLab как смонтированная файловая система.

## Полезные советы

- Не используйте бакеты с точками в имени.
- Для больших объёмов мелких файлов FUSE-режим может работать медленно.
- Ключ лучше хранить в Secrets DataSphere, а не в коде.
